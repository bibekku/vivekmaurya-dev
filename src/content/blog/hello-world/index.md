This is my first post, written in Markdown. This site is powered by [**Astro**](https://docs.astro.build), **Cloudflare**, and **GitHub Pages**. I'm eternally thankful for the hard work put in by the open source community that makes powerful software available to use for free.

I hope I'm able to keep up the habit of journaling things in here. The idea is to take notes whenever I learn something new, and include a minimal working example -- mostly so I can look back.

Using AI to write these would be against the point of it all, so I would try to keep it to a minimum, most likely nothing. I do admit I'm using AI to get the scaffolding up and running; it's great at things like that.

I'm also aiming to post some of my Blender explorations here. In no world would I call myself an artist, but at the same time who am I to call my Blender work not art?

I'm not writing this for an audience necessarily. Still, I think screaming into the void is healthy for me.
